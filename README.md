# Анализ семьи

Приложение (PWA) для анализов всей семьи: сравнение «было → стало», таблицы, динамика, рекомендации.

- `index.html`, `app.js`, `style.css` — приложение
- `kb.js` — справочник: что означает показатель, причины отклонений, что делать
- `data.enc.js` — **зашифрованные** данные семьи (AES-256-GCM, расшифровка в браузере по паролю)
- `tools/crypt.mjs` — шифрование/расшифровка данных

Обновление данных:

    node tools/crypt.mjs dec data.enc.js family.json <пароль>
    # добавить анализы в family.json
    node tools/crypt.mjs enc family.json data.enc.js <пароль>

Открытый `family.json` в репозиторий не коммитить.
